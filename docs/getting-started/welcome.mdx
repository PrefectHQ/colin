Colin is a **context engine** for building context pipelines—extract from sources, transform with LLMs, load to outputs. Write templates that reference other documents, pull from GitHub, Linear, Slack, databases via MCP. When sources change, Colin recompiles. Your context and skills stay fresh automatically.

<CodeGroup>

```markdown Template
---
name: Product Brief
colin:
  cache: auto
---

# About Us

{{ ref('company').content }}

# What Customers Are Saying

{{ colin.mcp.intercom.resource('feedback/recent').content | llm_extract('top 3 themes') }}
```

```markdown Output
---
name: Product Brief
---

# About Us

Acme Corp builds developer tools that streamline CI/CD
pipelines. Founded in 2020, we serve over 500 enterprise
customers including Fortune 100 companies.

# What Customers Are Saying

1. **Speed**: Customers consistently praise deployment times
2. **Reliability**: Zero-downtime deployments mentioned frequently
3. **Support**: Fast response times noted in multiple conversations
```

</CodeGroup>

The `ref()` function fetches content from another document and registers a dependency—so Colin recompiles this document when `company` changes. The `| llm_extract()` filter passes content through an LLM with your prompt. MCP resources pull live data from external systems.

## Why Colin?

Context goes stale. Someone writes a skill describing your deployment process. A month later, CI changed, environments got renamed, the approval flow is different. The skill is wrong. The agent is wrong. Nobody noticed.

Colin solves this:

**Live sources**: Templates reference data from MCP servers, other documents, and APIs. When sources change, dependents recompile.

**Dependency tracking**: `ref()` builds a graph. Colin compiles in topological order and knows exactly what depends on what.

**LLM synthesis**: Extract specific information, summarize across sources, synthesize with `{% llm %}` blocks. All cached by input hash.

**Full lineage**: The manifest tracks every compilation—what sources, what LLM calls, what outputs. Trace any context back to its origins.

## About the Name

Colin stands for **Co**ntext **Lin**eage. It's also a nod to the [Hitchhiker's Guide to the Galaxy](https://en.wikipedia.org/wiki/Colin_(The_Hitchhiker%27s_Guide_to_the_Galaxy))—a helpful robot that, despite being "a genuine people personality," really just wanted to make itself useful.
