Colin is a **context compiler** for the AI era. It takes interconnected source documents, resolves dependencies, applies transformations (including LLM calls), and compiles them to output formats.

<CodeGroup>

```markdown Model
---
name: Product Brief
---

# About Us

{{ ref('company').content }}

# What Makes Us Different

{{ ref('company') | extract('top 3 differentiators') }}
```

```markdown Compiled
---
name: Product Brief
---

# About Us

Acme Corp builds developer tools that streamline CI/CD
pipelines. Founded in 2020, we serve over 500 enterprise
customers including Fortune 100 companies.

# What Makes Us Different

1. **Intelligent Caching**: 80% faster deployments
2. **Enterprise Scale**: Fortune 100 proven
3. **Developer Experience**: Zero-config setup
```

</CodeGroup>

The `ref()` function fetches content from another document while registering a dependency edge—so Colin recompiles this document when `company` changes. The `| extract()` filter passes content through an LLM with your prompt. Colin caches LLM calls by input hash, so unchanged inputs return cached results instantly.

## Why Colin?

Context is scattered everywhere—project trackers, customer conversations, documentation, databases. Agents need this context synthesized into useful formats: skills they can load on-demand, system prompts that shape their behavior, documentation for humans and machines.

Today, this synthesis is manual. Someone writes a skill by hand, copy-pasting from various sources, hoping they didn't miss anything. When sources change, the skill goes stale. There's no lineage, no caching, no way to know what depends on what.

Colin solves this with:

**Interconnected context**: Real-world context isn't isolated. Your product docs reference your company overview. Your API specs reference your data models. Colin makes these relationships explicit and manageable.

**Incremental builds**: Change one source document and only rebuild what depends on it. No more reprocessing everything.

**LLM caching**: LLM calls are cached by input hash. Same input, same output, no API call.

**Full lineage**: The manifest tracks everything. You can see exactly what changed, when, and why—complete traceability across your context graph.

## About the Name

Colin stands for **Co**ntext **Lin**eage. It's also a nod to the [Hitchhiker's Guide to the Galaxy](https://en.wikipedia.org/wiki/Colin_(The_Hitchhiker%27s_Guide_to_the_Galaxy))—a helpful robot that, despite being "a genuine people personality," really just wanted to make itself useful.
