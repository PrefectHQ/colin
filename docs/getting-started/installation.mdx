## Install Colin

We recommend using [uv](https://docs.astral.sh/uv/getting-started/installation/) to install and manage Colin.

If you plan to use Colin in your project, add it as a dependency:

```bash
uv add colin-py --prerelease=allow
```

Alternatively, install directly with `pip` or `uv pip`:

<CodeGroup>
```bash uv
uv pip install colin-py --prerelease=allow
```

```bash pip
pip install colin-py
```
</CodeGroup>

<Note>
Colin currently depends on a pre-release version of FastMCP. When using `uv`, you must include the `--prerelease=allow` flag. This requirement will be removed once FastMCP releases a stable version.
</Note>

### Verify Installation

To verify that Colin is installed correctly, run:

```bash
colin --version
```

You should see output like:

```
0.1.0
```

## Requirements

- Python 3.10 or higher
- An LLM provider API key (for LLM blocks)
